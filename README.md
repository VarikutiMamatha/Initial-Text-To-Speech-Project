# Text To Speech Using ElevenLabs API

## Project Overview

This project converts text into speech using the ElevenLabs API and Python.

The user enters text in the Python program, and ElevenLabs generates realistic speech audio which is saved as an MP3 file.

## Technologies Used

- Python
- ElevenLabs API
- VS Code

## Project Workflow

1. Install ElevenLabs Python package.
2. Generate API key from ElevenLabs.
3. Import ElevenLabs libraries.
4. Connect to ElevenLabs using API key.
5. Provide input text.
6. Convert text to speech.
7. Save generated audio as MP3.
8. Play the audio output.

## Files

### tts.py
Main Python program for text-to-speech conversion.

### output.mp3
Generated speech output.

The program generates a speech audio file named:
